# 仪表盘

仪表盘是 GitBuddy 的主页面，展示所有收藏仓库的每日提交量统计。

## 页面结构

### 顶部状态栏

- 当前时间、最近提交时间、最近提交仓库与分支
- 全局搜索框，支持仓库名称/路径模糊搜索

### 左侧项目列表

已收藏的仓库列表，每个卡片显示：

- 仓库名称与路径
- 今日提交量（与目标对比的进度环）
- 收藏状态（星标）
- **刷新历史记录**按钮（按需回填近 365 天数据）

### 主内容区

- **总览卡片**：今日/昨日总提交量、总文件变更数
- **趋势折线图**：每日代码提交量趋势（近 30 天）
- **提交热力图**：全年每日提交密度（GitHub 风格）

## 功能详解

### 仓库收藏

未收藏的仓库仅显示名称与收藏按钮，不加载统计数据。点击星标后：

1. 卡片展开显示完整统计信息
2. 出现「刷新历史记录」按钮
3. 点击后触发 git log 回填，等待完成后卡片自动刷新

### 目标进度

在 **设置** 页面可配置每日代码量标准（默认 500 行）。

- 进度环显示今日 vs 目标的完成情况
- 未达标时显示告警提示（工作日有效）
- 周末/节假日不显示告警

### 项目分组

GitBuddy 自动将仓库按父目录名称分组为项目：

- 同一目录下的多个仓库归为一个项目（如 `github.com/my-org/repo1` 与 `repo2` 属于同一项目）
- 支持手动调整项目级别（提升或降低分组粒度）
- 项目可合并（将多个项目合并为一个）或拆分（将一个项目拆分为多个）
