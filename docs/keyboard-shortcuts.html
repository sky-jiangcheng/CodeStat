快捷键参考

快捷键功能说明
⌘/Ctrl + K打开命令面板快速搜索笔记、待办并跳转项目
⌘/Ctrl + 数字键切换页面1=仪表盘 2=知识库 3=设置
Esc关闭面板/对话框关闭命令面板、编辑器等

命令面板

按 ⌘/Ctrl + K 打开命令面板，支持：

  • 笔记搜索：输入关键词，模糊匹配标题与内容
  • 待办跳转：搜索待办事项，点击跳转至对应项目
  • 项目导航：输入项目名，快速进入项目详情页

导航

  • 左侧边栏可点击切换仪表盘 / 知识库 / 设置页面
  • 知识库页面支持按类型过滤（全部 / 知识 / 日志 / 想法）
  • 项目详情页可收藏/取消收藏，展开或收起技术栈卡片
